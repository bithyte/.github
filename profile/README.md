# bithyte

Small tools for working with AI agents, mostly for Claude Code users.

| Project | What it does |
| --- | --- |
| [jaypost](https://github.com/bithyte/jaypost) | Lets your agents and scripts ask you before they act. The question pops up in Telegram or Discord, you tap a button, they get the answer. Runs on your machine. |
| [ribbon](https://github.com/bithyte/ribbon) | A configurable status line for Claude Code. Needs Node 24 or newer. |
| [claude-plugins](https://github.com/bithyte/claude-plugins) | Our Claude Code plugin marketplace: code, jaypost, session and tweaks. |
| [mcp-dock](https://github.com/bithyte/mcp-dock) | An OAuth-protected gateway that exposes local stdio MCP servers over streamable HTTP. Early, v0.1.1. |
