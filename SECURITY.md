# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead:

1. Go to the affected repo's **Security** tab.
2. Click **Report a vulnerability**.

Include what you found, how to reproduce it, and which version you tested. You'll get a reply once someone has looked at it; fixes ship in a normal release and the advisory is published after that.

## Supported versions

Only the latest release of each project gets security fixes.
